# 📚 BiblioTech — Frontend

Aplicativo mobile desenvolvido com **React Native** e **Expo** para gerenciamento de bibliotecas e acervos bibliográficos. O sistema permite que usuários autenticados realizem consultas, cadastros e gerenciamento de livros por meio de uma interface intuitiva e responsiva.

---

## 🚀 Sobre o Projeto

O **BiblioTech** foi criado com o objetivo de modernizar o gerenciamento de bibliotecas, oferecendo uma experiência simples e eficiente para consulta e administração do acervo.

A aplicação consome uma API REST própria desenvolvida em Node.js, responsável pela autenticação de usuários e gerenciamento dos dados da biblioteca.

---

## 🛠 Tecnologias Utilizadas

* React Native
* Expo SDK 54
* React 19
* React Navigation
* Axios
* AsyncStorage
* Expo Vector Icons

---

## 📱 Funcionalidades

* Autenticação de usuários
* Visualização do catálogo de livros
* Cadastro de novos livros
* Edição de informações dos livros
* Exclusão de livros
* Busca e gerenciamento do acervo
* Navegação entre telas utilizando React Navigation
* Persistência de sessão com AsyncStorage

## ▶️ Executando o Projeto

### 1. Clone o repositório

```bash
git clone <url-do-repositorio>
```

### 2. Acesse a pasta do projeto

```bash
cd frontend
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
npm start
```
